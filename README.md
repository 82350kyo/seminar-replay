# セミナー録画ページ（seminar-replay-lp）

このリポジトリは、セミナーの録画動画を公開するための1枚もののランディングページ（LP）です。
HTMLファイル1つ（`index.html`）だけで完結していて、見た目（デザイン）も動作（JavaScript）もすべてこの中に書かれています。

デザインは「黒×ゴールド」を基調にした高級感のあるモダンデザインです（社内呼称：デザイン案A「モダン×ゴージャス」）。

公開URL: https://82350kyo.github.io/seminar-replay/

---

## このページでできること

- カウントダウンタイマー付きで「視聴受付の締切」を表示
- 締切前は動画（セミナー録画）を埋め込み表示
- 締切を過ぎると自動で「受付終了」の表示に切り替わる
- 公式LINEへの「友だち追加」ボタンを設置
- セミナー参加特典（No.01〜05）と、個別ロードマップ作成会の参加特典（No.06〜08・ロック表示）を紹介するカードを設置

## どこを書き換えれば運用できるか（重要・ここだけでOK）

`index.html` の中に `CONFIG` という設定用のブロックがあります。
ファイルを開いて `CONFIG` で検索すると、以下のような場所が見つかります。

```js
const CONFIG = {
  DEADLINE: "2026-08-02T23:59:59+09:00",
  VIDEO_URL: "https://utage-system.com/video/OZxIqf3HQfLP",
  LINE_URL: "https://dk8lywti.autosns.app/line",
};
```

この3行だけを書き換えれば、内容を運用できます。他の部分（デザインやレイアウトなど）は触らなくて大丈夫です。

| 項目 | 意味 | 書き方の例 |
|---|---|---|
| `DEADLINE` | 視聴受付の締切日時。この日時を過ぎると自動で「受付終了」表示に切り替わります | `"2026-08-02T23:59:59+09:00"`（末尾の `+09:00` は日本時間を表す固定値なので消さないでください） |
| `VIDEO_URL` | 埋め込むセミナー動画のURL（UTAGEなどの動画配信サービスの埋め込み用URL） | `"https://utage-system.com/video/xxxxxxxx"` |
| `LINE_URL` | 公式LINEの「友だち追加」URL | `"https://line.me/R/ti/p/xxxxxxxx"` |

※ `LINE_URL` を空文字 `""` にすると、ボタンが「準備中」と表示された押せない状態になります。まだLINEのURLが決まっていないときはこの状態にしておけます。

## 【重要】締切日（DEADLINE）を変更したときの注意

`CONFIG.DEADLINE` を書き換えても、ページの途中に表示されている

「◯月◯日（◯）23:59 まで」

という文章は**自動では変わりません**。この文章は`index.html`の中に直接、文字として書き込まれている場所が2箇所あります（申し込みボタンの上あたり、1箇所目は「個別ロードマップ作成会に参加する」ボタンの上、2箇所目は「この特典を受け取る」ボタンの上です）。

そのため、`DEADLINE`（カウントダウンの締切）を変更したときは、必ずこの2箇所の日付も**手作業で**同じ日付に合わせて直してください。

やり方：
1. `index.html` をテキストエディタで開く
2. `まで</span>` という文字列で検索（Cmd+F / Ctrl+F）すると2箇所ヒットします
3. 両方とも「◯月◯日（◯）23:59 まで」の部分を、`DEADLINE`に設定した日付・曜日に書き換える

（曜日を間違えないよう、カレンダーで確認してから書き換えてください。もし迷ったら、日付だけ伝えていただければこちらで直します。）

## 特典カードの文言・リンク先の直し方（No.01〜08）

ページの中には「特典（プレゼント）」を紹介するカードが8枚あります。

- **No.01〜05**：「セミナー参加特典」として、誰でもすぐタップして受け取れるカード（リンク付き）
- **No.06〜08**：「個別ロードマップ作成会 参加特典」として、鍵アイコンで中身をぼかした“ロック中”のカード（参加者だけに渡す想定のため、あえてリンクを付けていません）

これらは `index.html` の `<body>` 部分（HTMLタグで書かれている箇所）にそのままテキストとして書かれています。

1. `index.html` をテキストエディタ（メモ帳やVS Codeなど）で開く
2. 変更したい特典の見出しや説明文をそのまま検索（Cmd+F / Ctrl+F）して探す（`No.01`〜`No.08` で検索すると見つけやすいです）
3. 日本語の文章部分だけを書き換える（タグ `<div>` や `class="..."` などの英語部分は変更しない）
4. リンク先を変える場合は `href="..."` の中のURLだけを書き換える（No.01〜05のみ。No.06〜08にはリンクがありません）

### 【重要】特典の見出し（番号＋サブタイトル＋特典名）の文字数制限

各カードの上部にある「No.01」「サブタイトル」「特典名」の1行は、**スマホの一番狭い画面（320px幅）でも1行に収まるよう、1pxの余裕もないギリギリのサイズで作られています**。

そのため、**今の文言より長い文字数に変更すると、右側の文字が画面からはみ出してしまいます。** 見出し（サブタイトル・特典名）を変更する場合は、できるだけ今と同じかそれより短い文字数に収めてください。長くしたい場合は、変更前に一度声をかけていただければ、はみ出さないか確認したうえで反映します。

判断に迷う場合や、大きくデザインを変えたい場合は、無理に自分で編集せず声をかけてください。一緒に直します。

## 変更後にどうやって反映するか

このページはGitHub Pagesという仕組みで公開されていて、`main`ブランチに変更を送る（push する）と、数分後に自動で公開ページに反映されます。

ターミナル（コマンド操作）に慣れていない場合は、変更したい内容を伝えていただければこちらで反映します。
自分で反映する場合は、このフォルダ（`/Users/kyo/seminar-replay-lp`）で以下を実行してください。

```bash
git add index.html
git commit -m "内容を更新"
git push
```

pushしてから1〜3分ほど待つと、公開URL（https://82350kyo.github.io/seminar-replay/ ）に反映されます。

## ファイル構成

- `index.html` … 公開中のページ本体（デザイン・文言・設定すべてがこの1ファイルに入っています）
- `README.md` … このファイル（使い方の説明）
- `designs/` … デザイン案を置いておく作業用フォルダ
  - `pattern-a-luxury.html` … 現在本番で使っている「黒×ゴールド」デザイン案。**今後もこのファイルを直接編集してから `index.html` にコピーする運用にしています。**（消さないでください）
  - `pattern-b-ai.html` … 別デザイン案（未採用・検討用に保管）
- `backup/` … 過去のデザインのバックアップを置いておくフォルダ
  - `index-before-luxury.html` … 黒×ゴールドデザインに切り替える直前の旧デザイン（万一デザインを戻したくなったときはこのファイルを `index.html` に上書きしてください）

### 今後デザインを修正するときの流れ

1. `designs/pattern-a-luxury.html` を編集する
2. 問題なければ `designs/pattern-a-luxury.html` の中身をそのまま `index.html` にコピーする
3. 上記の「変更後にどうやって反映するか」の手順でpushする
